O executável europeu inicia pelo ponto de entrada recompilado em ARM64. O backend Xenos do RexGlue recebe o ring buffer, traduz shaders reais para SPIR-V, cria módulos/pipelines Vulkan e apresenta imagens da abertura. A renderização real usa **RexGlue Xenos → Vulkan**, não Plume. O Plume continua disponível nos dois testes gráficos anteriores: diagnóstico isolado e ponte de framebuffer `VdSwap`. Reescrever toda a tradução Xenos usando a abstração Plume não foi feito. Não apresentar a tela de teste quadriculada da versão 0.3 como imagem do jogo.

## Correções importantes deste ponto

1. `android/rexglue/xenos-dependencies.cmake` e CMake principal ativam o plugin Xenos, tradutor SPIR-V e Vulkan do SDK. Dependências adicionais fixadas: glslang, Vulkan-Headers, VMA, SPIRV-Tools headers e SPIRV-Headers.
2. `android_game_window.h` adapta a SurfaceView ao Window/Presenter do RexGlue. O thread JNI possui o contexto e bombeia eventos/pintura; Java controla a janela e encerra o processo ao sair.
3. `android_vulkan_loader.cpp` carrega o driver do sistema ou selecionado via adrenotools. O patch de `vulkan_instance.cpp` usa esse carregador no Android. O Plume usa símbolos locais para evitar misturar implementações VMA das duas bibliotecas.
4. Sampler: `kBaseMap` com anisotropia forçava mip linear e disparava assert em `texture_cache.cpp:876`. O limite máximo de LOD agora coincide com o mínimo nesse caso, seguindo a implementação D3D12 do SDK; o acréscimo de 0,25 permanece somente sem anisotropia. Referência: [VkSamplerCreateInfo](https://docs.vulkan.org/refpages/latest/refpages/source/VkSamplerCreateInfo.html), descrição de seleção do nível base.
5. Áudio: `UnregisterClient` liberava driver/argumento enquanto um callback convidado ainda os usava. A liberação é adiada até o retorno do callback e o slot não é reutilizado nesse intervalo. Isso corrigiu o crash observado em `AudioSystem::SubmitFrame`. Ainda merece teste específico de concorrência/repetição; não manter o lock global durante a execução convidada.
6. A ABI do plugin GPU local foi incrementada para 2 porque a ponte anterior adicionou `PresentFrontBuffer` à interface. Plugin e runtime são compilados juntos.

Todas as alterações no checkout ignorado do SDK estão preservadas em `android/rexglue/android-platform.patch`, conferido por `git apply --reverse --check` e `git diff --check` no SDK. As licenças upstream e o contexto do patch mantêm espaços originais; o check de whitespace do código próprio passou com esses dois grupos excluídos.
